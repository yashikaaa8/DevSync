About the Campus Club Management System

An academic full-stack project built for demonstration of RESTful APIs, explicit direct DOM manipulation, and database persistence.

🎯 Project Purpose

In many universities, student club information is scattered across physical notice boards, social media groups, and spreadsheets.

This web application centralizes club profiles, leadership details, and meeting schedules into a single, clean platform where student activities can be managed seamlessly.

⚡ Core Features

  • Real-time Dashboard: Fetches live counts and featured clubs from MongoDB.
  • Clubs Directory: Dynamic grid with instant search and category filtering.
  • Full CRUD Operations: Create, Read, Update, and Delete clubs via REST API.
  • Direct DOM Manipulation: No frontend frameworks; pure vanilla JavaScript.
  • Dual Validation: Input validation on both client-side and backend.

🔄 Full-Stack Request Flow (Frontend → Backend → Database)

Here is how data travels through the system when a user interacts with the application:

Step 1: User Action in Browser (Frontend)
The student submits a form or clicks an action button. An event listener attached via element.addEventListener() captures the event and prevents default page reload.
Step 2: Fetch API Dispatch (HTTP)
Vanilla JavaScript initiates an asynchronous request using fetch('/api/clubs', { method, body }) carrying JSON formatted data across HTTP.
Step 3: Express Routing & Validation (Backend)
Express parses the request body using express.json(). The router handles the endpoint, validates the input parameters, and passes the operation to the Mongoose ODM.
Step 4: Mongoose & MongoDB Persistence (Database)
Mongoose executes the operation (e.g. Club.find(), Club.create(), Club.findByIdAndUpdate(), or Club.findByIdAndDelete()) on the campus_club_db database.
Step 5: JSON Response & Direct DOM Rendering
Express returns an HTTP status code (200, 201, 400, 404, or 500) and JSON response. The frontend receives the data and dynamically builds DOM nodes using document.createElement(), assigns values via element.textContent, and mounts them with element.replaceChildren().

🛠️ Technologies Used

Layer Technology Role in Project
Frontend Markup HTML5 Semantic structure of all six application pages.
Styling CSS3 (Custom) Responsive university theme, CSS Grid, Flexbox, variables, and transitions without frameworks.
Client Scripting Vanilla JavaScript (ES6+) Asynchronous Fetch API calls, event listeners, and explicit direct DOM manipulation.
Runtime Node.js (v22+) Server-side JavaScript runtime executing the backend application.
Web Framework Express.js REST API routing, JSON middleware, static asset serving, and HTTP status handling.
Database MongoDB Document-oriented NoSQL database storing club records in BSON format.
ODM Mongoose Schema definition, field-level validation, and model queries.
